# Complexity Router

Use the smallest process that still protects correctness, safety, and maintainability.

## Small Task

- Direct fix allowed.
- Still summarize what changed.
- Run minimal validation.

Use for isolated, low-risk edits with obvious success criteria.

## Medium Task

- Create a short plan first.
- Identify affected files.
- Implement the change.
- Run targeted checks.

Use when several files, behavior changes, or user-facing outcomes are involved.

## Complex Task

- Create a mission brief.
- Create an architecture plan.
- Define milestones.
- Identify risks.
- Require review gates.
- Execute in phases.
- Update memory files.

Use when the work spans subsystems, has unclear requirements, or needs durable context.

## Critical Or High-Risk Task

- Require explicit human approval.
- Define rollback plan.
- Avoid destructive operations.
- Document safety boundaries.

Use for production-impacting, security-sensitive, irreversible, permission-changing, billing-related, authentication-related, or data-destructive work.
