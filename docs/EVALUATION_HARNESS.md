# Evaluation Harness

Use this harness to determine whether an agent completed the actual mission and left the project easier to continue.

Answer these questions:

- Did the agent complete the actual mission?
- Did it change the correct files?
- Did it avoid unrelated changes?
- Did it run or explain validation?
- Did it document risks?
- Did it preserve safety?
- Did it leave the project easier to continue?

Pair this document with the reusable checklists in `checklists/`.
