# Quality Gates

Serious changes must pass these gates before shipping:

- requirements clear
- architecture reviewed
- security boundaries reviewed
- tests added or justified
- lint/build passes
- edge cases considered
- rollback path documented
- docs updated
- handoff notes written

# Quality Gate Checklist

- [ ] Mission is clear
- [ ] Non-goals are clear
- [ ] Architecture impact reviewed
- [ ] Security impact reviewed
- [ ] Tests added or existing tests updated
- [ ] Build/lint/typecheck passes
- [ ] Edge cases considered
- [ ] Rollback path documented
- [ ] Documentation updated
- [ ] Handoff completed
